# 工具管理システム (ToolAddDb)

現場における工具の貸出・返却状況の視覚化、紛失防止、管理業務の効率化を目的とした Web アプリケーションです。

## 解決する課題・背景
- **貸出状況の不透明さ:** 「誰が・何を・いつまで借りているか」が不透明で発生する紛失や作業遅延の防止。
- **管理コストの削減:** 複数工具の個別の貸出・返却処理の手間を省く一括ステータス変更機能の実装。
- **返却遅延の防止:** 貸出時の返却予定日（デフォルト7日後）の自動算出と、期限切れ工具の視覚的アラート通知。

## 主な機能
- **工具CRUD & カテゴリ管理:** 工具情報・カテゴリの追加・編集・削除
- **貸出・返却トグル処理:** 貸出時の返却予定日設定と返却時の自動期限クリア（`NULL` 設定）
- **一括貸出・返却処理:** 複数チェックボックス選択による一括ステータス変更
- **返却期限切れアラート:** 期限を過ぎた工具を自動検知し画面上部へ警告表示
- **履歴ログ記録:** 操作者名（UserName）とタイムスタンプを含む変更履歴の自動作成
- **動的複合検索:** 工具名（部分一致）・保管場所・カテゴリ・ステータスの組み合わせ検索

## 技術スタック
- **バックエンド:** VB.NET (.NET 8.0) / ASP.NET Core Minimal API
- **データベース:** SQLite (`Microsoft.Data.Sqlite`)
- **フロントエンド:** HTML5 / CSS3 (2カラムレイアウト) / JavaScript (Vanilla JS, Fetch API)
- **アーキテクチャ:** リポジトリパターン (データアクセス層の分離), トランザクション制御

## 設計のこだわり・技術的工夫
1. **トランザクションによるデータ整合性の担保**
   工具のステータス更新と `ToolLogs` への履歴追加を同一トランザクション内で実行し、処理失敗時は確実にロールバックを行ってデータの不整合を防いでいます。
2. **柔軟な動的 SQL 構築**
   `WHERE 1=1` パターンを採用し、NULL 許容型（`Nullable(Of T)`）の判定を組み合わせて安全で効率的なパラメータ化クエリを生成しています。
3. **データ型に配慮した DB 制御**
   `DueDate`（返却期限）の更新にあたり、VB.NET の三項演算子と `CObj(DBNull.Value)` を活用して SQLite への `NULL` 書き込みを安全に制御しています。
